03 · Maze Generation

Four classic algorithms · same grid · radically different mazes.

Reuses the grid renderer built for #02 Pathfinding.

Planned interactive demo

Recursive DFS · Prim's · Kruskal's · Wilson's all carve a maze of configurable size. The same algorithms produce visually distinct styles — DFS makes long winding corridors, Prim's makes spiky offshoots, Kruskal's looks chaotic, Wilson's is slowest but produces an unbiased uniform-spanning-tree maze.

What it teaches

  • How spanning-tree algorithms double as maze-generation algorithms.
  • The bias-vs-uniformity trade-off: a "naturally biased" maze is fast to generate but visually predictable; a uniform maze takes longer but feels random.
