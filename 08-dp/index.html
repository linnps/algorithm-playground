Planned interactive demo

Type two strings (for LCS / edit distance) or items + weights (for knapsack). The 2D DP table fills cell-by-cell, colour gradient by value, with the optimal traceback path lit up in red after the table completes.

What it teaches

  • The mental shift from "recursive with memoization" (top-down) to "iteratively fill the table" (bottom-up) — same answer, different code shape.
  • Why DP problems often have an obvious recurrence but a non-obvious traceback — the table tells you the cost; the path through the table tells you the solution.
  • The space-optimization trick: most DP tables only need the previous row, so O(n²) space → O(n) is often free.
