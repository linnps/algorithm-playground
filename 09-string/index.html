Planned interactive demo

Pick a haystack and a needle. KMP first builds its failure function (animated), then the matching pass — when a mismatch occurs, the needle slides by the failure-function offset instead of restarting from zero. Side-by-side with naive O(nm), you can see KMP completing matches the naive algorithm is still chewing through.

What it teaches

  • The failure function is the key insight: pre-compute "if I fail at position k of the needle, how far back can I safely jump?"
  • Why Rabin-Karp's rolling hash makes it preferred for multi-pattern matching — KMP wins for one pattern; Rabin-Karp wins for many.
  • How a problem that looks like O(nm) becomes O(n+m) once you stop throwing away information.
