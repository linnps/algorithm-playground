Planned interactive demo

Click on the canvas to add nodes; drag between nodes to add directed edges. With the graph in place, run BFS / DFS / topological sort / Tarjan SCC and watch nodes coloured by traversal depth, finish order, or strongly-connected component.

What it teaches

  • BFS layers vs DFS chains — same graph, completely different shape of exploration.
  • Topological sort only exists when the graph has no cycles — the algorithm itself doubles as a cycle detector.
  • Tarjan's SCC is one of those algorithms that looks magical until you realize it's "DFS plus two integer arrays."
